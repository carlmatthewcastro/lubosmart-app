# Original demonstration assets

The current catalog uses the real photographs in `photos/`. See
[photo attribution](photos/ATTRIBUTION.md) and `photos/sources.json` for each
photographer, original file page, license, acquisition URL and checksum. There are
38 actual photographs for the 45 fictional product listings. Related book and coffee
listings reuse some photos; editions, packaging, quantities and exact models remain
illustrative. No AI image generation was used for these photographs.

`catalog.svg` is the original LubosMart placeholder illustration, retained only to
identify the legacy demo image paths. Fresh seeds use photographs. The explicit
`lubosmart:demo-photos` command upgrades legacy owned placeholders while preserving
custom seller-uploaded images, inventory, prices, users and order progress.

`evidence.png` is an original text graphic labeled “SYNTHETIC DEMO EVIDENCE” and
“No real delivery, identity or payment.” It is used only as historical synthetic
registration, delivery and return evidence. It is never evidence of actual identity,
physical transport, cash receipt or payment. Live demonstrations must capture new
proof through the normal application actions.

These project-created assets may be included with LubosMart demonstration releases.
