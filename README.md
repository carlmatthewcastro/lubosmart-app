# LubosMart

Shopee-inspired, multi-seller e-commerce project with **Cash on Delivery (COD) only**.

Built with Laravel 12, Socialite, React 19, Inertia v2, TypeScript, Tailwind CSS v4, and Vite. The existing deployment uses an Azure VM with Docker Compose, Apache, MySQL, and Caddy.
