## Reading the records

- Older role names, routes and pre-split source paths describe the repository at the review date. Current identifiers and schema are in [Architecture](../ARCHITECTURE.md#database).
- Early scan proposals and whole-parcel return descriptions are superseded by the [current workflows](../WORKFLOWS.md). Financial credit and physical return custody remain separate.
- Older browser evidence paths under `storage/app/` are historical references. Current harness output belongs in the ignored root `.tools/development-artifacts/` directory. Local evidence is not guaranteed to be included in a source checkout.
- Test totals and performance samples apply only to the recorded run. They do not certify current production behavior, physical devices or accessibility.

The reports mention supplied ERP/category PDFs, an earlier ERP audit, a Logistics implementation/acceptance record and a homepage restoration report. Their original files or authoritative locations are not identified in this documentation set. Do not treat those references as available evidence or replace their missing contents with assumptions.

The [finance API reference](../api/FINANCE_2026_11_11.md) retains current compatibility details alongside dated updates; it remains under `api/` because clients still need it. Dated email verification evidence is retained in [Deployment](../DEPLOYMENT.md#mail-automated-coverage-and-ui-review).
